# AI-use disclosure

| Tool | Material use |

## Human ownership and review

Mohammed Ghazal selected the product direction, approved the master plan and implementation authority, owns the public repository and submission, and remains responsible for every design, code, license, security, deployment, and competition claim.

AI-generated material was not accepted merely because it was produced. Source changes were reviewed against the approved specification, protected by test-first contracts where behavior changed, and recorded with explicit verification limits. Release claims require fresh evidence from the exact source commit and deployed build.

The AI is not a team member, entrant, owner, or rights holder. It provided technical assistance under Mohammed Ghazal’s direction.

## Verification policy

The entrant reviewed and verified material before treating it as accepted project output. Where the available environment could not execute dependency-backed tests, browser automation, deployment, or official-client validation, the repository records those checks as pending rather than claiming success.

## Data and privacy

No real recipient, volunteer, address, phone number, credential, API key, or private organizational data was supplied for the application fixture. All displayed operational and contact data is original and fictional.
